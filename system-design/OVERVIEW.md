## Program Structure

### **Phase 1: Foundations** (Week 1-2)
Build your mental models and understand the WHY.

```
01-fundamentals/
├─ Scalability (vertical vs horizontal)
├─ Reliability (availability, fault tolerance)
├─ Trade-offs (CAP theorem, consistency)
└─ Capacity estimation (back-of-envelope math)

02-core-building-blocks/
├─ Load Balancers (algorithms, L4 vs L7)
├─ Caching (strategies, eviction policies)
├─ Databases (SQL vs NoSQL)
└─ Message Queues (pub-sub, work queues)
```

**Deliverable**: Can design simple systems and justify decisions

---

### **Phase 2: Patterns** (Week 3-4)
Master the building blocks of large-scale systems.

```
04-scaling-patterns/
├─ Replication (master-slave, master-master)
├─ Sharding (hash, range, consistent hashing)
└─ Microservices vs Monolith

06-data-patterns/
├─ CAP Theorem (deep dive)
├─ Consistency Models (strong, eventual, causal)
├─ Quorum-based Replication
└─ Conflict Resolution (CRDTs, vector clocks)
```

**Deliverable**: Can design scalable, reliable systems

---

## Key Features

### 🎓 Learning Methodology

**1. Active Learning**
- Not just reading - doing
- Design 1 system per day
- Draw diagrams for every concept
- Code implementation drills

**2. Spaced Repetition**
```
Day 1:  Learn concept
Day 3:  Quick review
Day 7:  Deep review
Day 30: Final review
```

**3. Deliberate Practice**
- Timed practice (45 min per design)
- Self-assessment after each
- Redo struggling problems
- Track progress metrics

**4. The Feynman Technique**
```
Learn → Teach Simply → Find Gaps → Review → Simplify More
```

### 📊 Built-in Tracking

**Progress Tracker** includes:
- [ ] Daily checklists
- [ ] Concept mastery checkboxes
- [ ] Problem completion log
- [ ] Mock interview scores
- [ ] Skills self-assessment

### 🧠 Interview Framework

**The 45-Minute Structure**:
```
1. Requirements    (5 min)  → Clarify scope
2. Estimation      (5 min)  → Do the math
3. API & Data      (5 min)  → Define interfaces
4. High-Level      (10 min) → Draw diagram
5. Deep Dive       (15 min) → Solve bottlenecks
6. Wrap-up         (5 min)  → Scale & edge cases
```

## 10x Interview-to-Production Workflow

For every practiced design:

1. **Interview run (45 min)**  
   Deliver a complete design using the framework.

2. **Architecture note (15 min)**  
   Write decisions, alternatives, and trade-offs.

3. **Risk review (15 min)**  
   Add top failure modes, abuse scenarios, and data risks.

4. **Operations pass (20 min)**  
   Define SLOs, alert thresholds, dashboard, and runbook.

5. **Rollout pass (10 min)**  
   Add migration/canary/rollback plan.

6. **Retrospective (10 min)**  
   What changed from interview answer to production-ready plan?

---

## Extended Scoring (Beyond 35-Point Interview Rubric)

Add a second score (0-10 each):
- Operability (alerts, runbooks, ownership clarity)
- Resilience (failure handling and degraded modes)
- Security/privacy (abuse prevention, data protection)
- Cost awareness (capacity + spend trade-offs)
- Evolution strategy (schema/versioning/migrations)

Target: **40+/50** before considering a design "production-ready."

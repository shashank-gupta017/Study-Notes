## 📊 Pattern Recognition Guide

### When to Use Each Pattern:

**Two Pointers:**
- Finding pairs/triplets in sorted/sortable array
- Optimizing from both ends
- Container/area problems
- Example: Container With Most Water

**Sliding Window:**
- Contiguous subarray/substring problems
- Variable or fixed window size
- Maintain window invariant
- Examples: Longest Substring, Longest Repeating, Max Subarray

**Stack:**
- Matching pairs (parentheses, tags)
- Next greater/smaller element
- Design with O(1) operations
- Examples: Valid Parentheses, Min Stack, Daily Temperatures

**Linked List Pointers:**
- In-place reversal
- Merging sorted lists
- Cycle detection (fast & slow)
- Examples: Reverse List, Merge Lists, Cycle Detection
